# Cotsel Protocol Specification

The specification is the implementation authority beneath the product
whitepaper. It defines:

1. the settlement state machine and terminal states;
2. conservation, recipient, milestone, tenant, and replay invariants;
3. attestation authorities, quorum, domain, nonce, and expiry;
4. evidence schema, issuer identity, provenance, signatures, and revocation;
5. dispute, freeze, unfreeze, refund, and recovery authority;
6. immutable version and tenant deployment topology;
7. stablecoin, chain, confirmation, and exposure policy;
8. public command, event, ABI, and error semantics;
9. deployment verification and retirement rules;
10. security and adopter-neutral acceptance tests.

The whitepaper explains the product direction. This specification defines the
behavior engineers implement and the properties automated tests must prove.
